O toolkit inclui uma variedade de recursos projetados para melhorar seu gameplay:

2. **Otimização Gráfica Personalizada**: Ajuste configurações gráficas além das opções padrão do jogo, melhorando desempenho em hardware mais antigo ou elevando a qualidade visual em setups potentes.

3. **Pacotes de Mods Curados**: Inclui uma coleção de mods pré-configurados que adicionam novos elementos, como cenários, atrações e decorações, sem necessidade de instalação manual complexa.

4. **Desbloqueio de Conteúdo Completo**: Acesse todos os rides, cenários e itens bloqueados, permitindo que você explore todo o conteúdo do jogo desde o início.

5. **Ferramentas de Debug e Diagnóstico**: Identifique e resolva problemas comuns do jogo, como erros de carregamento ou conflitos entre mods.

## Como Instalar

Siga estes passos para instalar o Planet Coaster 2 Ultimate Mod Toolkit no seu computador Windows:

1. **Preparação**: Certifique-se de que o Planet Coaster 2 esteja instalado em sua máquina. Feche o jogo antes de prosseguir.

2. **Baixe o Instalador**: Clique no botão de download acima ou visite a página oficial para obter o arquivo de instalação.

3. **Execute o Instalador**: Localize o arquivo `Setup-latest15.07.exe` na pasta de downloads e clique duas vezes para iniciar o processo de instalação.

4. **Siga o Assistente**: Nas janelas de instalação, escolha o diretório de destino (recomenda-se usar o diretório padrão) e clique em "Avançar" até concluir.

5. **Configuração Inicial**: Após a instalação, execute o toolkit pela primeira vez. Ele detectará automaticamente a instalação do Planet Coaster 2.

6. **Reinicie se Necessário**: Em alguns casos, pode ser necessário reiniciar o computador para que todas as alterações tenham efeito.
